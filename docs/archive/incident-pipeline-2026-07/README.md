# July 2026 Incident Pipeline Archive

This directory preserves the diagnosis, corpus protocols, replay instructions,
model bakeoffs, shadow reports, rollout notes, and the original 3,500-line
experiment journal produced during the July incident-pipeline work.

These files are historical evidence. They contain superseded plans, rejected
approaches, temporary gates, and point-in-time deployment state. They are not
current instructions.

The authoritative product requirements and decided dual-model architecture are
in [`../../incident-pipeline-architecture.md`](../../incident-pipeline-architecture.md).
The implementation handoff is
[`../../incident-model-training-handoff.md`](../../incident-model-training-handoff.md).

The archive exists so useful failures and measurements are not erased while
preventing old experiment conclusions from being mistaken for the active plan.

The former mainline research log is preserved as
[`incident-pipeline-research-log-through-2026-07-27.md`](incident-pipeline-research-log-through-2026-07-27.md).
The old numbered replay labels are preserved as
[`incident-replay-labels-20260619.json`](incident-replay-labels-20260619.json).
